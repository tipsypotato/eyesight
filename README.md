# eyesight

供医生进行眼球结构科普、常见眼病科普与互动演示的纯前端应用。以成人眼球模型说明结构、成像与机制；短导览和理解确认按需使用。

![eyesight 交互预览](preview.png)

## 在线演示与发布

访问：[eyesight 在线 demo](https://tipsypotato.github.io/eyesight/)。已于 2026-10-22 完成 GitHub Pages 发布和线上浏览器验证。

推送到 `main` 后，[GitHub Actions](https://github.com/tipsypotato/eyesight/actions/workflows/pages.yml) 使用 Node.js 26 安装锁定依赖、执行测试及类型检查/生产构建，再将 `dist/` 发布到 GitHub Pages；检查失败不会发布新版本。也可在 Actions 中选择 `main` 手动运行。

仓库 Settings → Pages 的 Source 使用 **GitHub Actions**。应用保留相对资源路径以兼容 `/eyesight/`；本地和线上使用同一构建配置。线上记录保存于该站点所在浏览器，与本地预览记录相互独立。部署方式参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

线上 HTML、JS、CSS、图标均返回 HTTP 200，内容与本地生产构建一致。已在内置 Chromium 验证模型渲染、结构选择、中英文切换、白内障变化示意、刷新恢复及返回探索；本次检查未记录浏览器警告或错误。回滚应用变更时，在 `main` 提交对应的 `git revert` 并推送，检查通过后会自动重新发布。

## 本地运行

需要 Node.js 22.12+（22.x）、24.x 或 26+，以及 npm。当前验证环境为 Node.js 26.5.0、npm 11.17.0。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`，开发服务仅绑定本机。

```sh
npm test -- --maxWorkers=1
npm run typecheck
npm run build
npm run preview
```

`dist/` 是生产静态文件，需通过 HTTP 服务访问；不能直接双击 `index.html`。预览默认地址为 `http://127.0.0.1:4173`。

## 当前功能

- **结构探索**：成人右眼、51 个组织/区域/空间，提供双语资料、搜索、定位、图层、隔离、关联观察、九种预设及三轴分层剖切。
- **眼外肌观察**：上/下/内/外直肌、上/下斜肌，显示肌腹、纵向纤维、肌腱与上斜肌滑车；支持中英文搜索、高亮、隔离、剖切和分层展开。在解剖探索中选择“眼外肌观察”查看全貌，或搜索 EOM 查看六肌。
- **结膜与眼睑**：球结膜、睑结膜，以及上下睑皮肤、眼轮匝肌、提上睑肌、睑板、睑板腺、Zeis 腺和 Moll 腺；睫毛随皮肤显示。在解剖探索中选择“结膜与眼睑”，结合图层和展开查看内外层次。视神经主干使用平滑圆截面，保留原有走行。
- **眼眶与内容物**：四面眶壁、肌锥内外脂肪、主要眶内神经、眼动脉、眼上/下静脉及泪腺；复用眼球、视神经、六条眼外肌和提上睑肌。选择“眼眶与内容物”预设观察空间关系，眶壁与脂肪默认半透明；支持独立图层、选取、定位、隔离、展开和覆盖眶尖的三轴剖切。
- **眼球交互**：旋转缩放、悬停与选中反馈、固定解剖方位、目标轮廓、分层展开及场景撤销；桌面与窄屏布局。
- **手机操作**：默认单指上下滚页、轻触选择结构；点击“操作模型”后旋转、缩放或拖动剖切框，退出后恢复滚页。说明、对照摘要和疾病详情统一随页面滚动；提供收起、展开、专注内容与返回模型。
- **光学演示**：正常聚焦、轴性近视、镜片矫正；眼轴、物距、调节、瞳孔、外镜片五类参数；二维/三维同源光路、同条件对照和定性测试图。
- **生理演示**：瞳孔、调节、光到神经信号，可播放、暂停、单步和重播。
- **四种常见眼病**：白内障混浊与散射、青光眼房水与损害、斜视双眼注视、弱视输入与视觉发育；正常/变化自由切换，说明与参数分别保存。
- **按需讲解辅助**：三条短导览、11 项可选操作、29 道理解确认题、独立会话及错题回顾，无完成门槛。
- **中英与恢复**：静态双语、独立 LLM 对照审校、版本化本地保存；语言切换保留参数、镜头、题序及答案。
- **启动与加载**：HTML 先显示双语加载卡，界面与三维引擎并行加载；按界面、引擎、模型、首帧四步更新进度，首帧成功后进入。提供重载入口，3D 启动失败时仍可阅读内容；对照模型另有局部进度。

完整操作、机制边界、验证与待办见 [《eyesight 功能进展与后续开发清单》](docs/development-status-2026-10-22.md)。

## 范围与待办

当前源码实现范围覆盖 T01—T13、六条眼外肌、结膜/眼睑及眼眶静态观察。T14 视网膜微观层级、T15 场景链接/PNG 导出/展示模式，以及结构图鉴和外部眼部外形资产仍为可选待办。线上 demo 随 `main` 分支的 GitHub Actions 成功发布而更新。

眼外肌为正常形态的静态解剖示意，不模拟收缩、肌力或手术效果；光路、导览、原有题目及眼病场景默认隐藏肌肉。旧浏览器记录自动补齐隐藏的肌肉图层，保留已有场景和答题记录。

结膜、眼睑与眼眶采用静态示意，原有场景默认隐藏新增组织，旧记录自动补齐图层；腺体数量、组织厚度及脂肪分叶为便于辨识而简化。骨性眼眶按四面眶壁展示，神经血管采用主干与代表性分支；七骨拆分、精细孔裂、完整神经血管网络、眨眼、泪膜/腺体分泌和完整泪道尚未实现。

这是参数化科普示意，几何、光学及疾病效果未经临床标定，不输出诊断、处方或疗效预测。独立 LLM 审校不等于医学专家审核；医学内容仍待专家审核。应用不采集患者资料，也没有账户或后端。

记录仅保存于当前浏览器；刷新后播放暂停，撤销栈与临时观察不恢复。清理浏览器存储会丢失本地记录。

## 验证与技术

本轮眼眶增补：33 个测试文件、555 项通过；TypeScript、生产构建与差异检查通过。新增覆盖眶壁包容、脂肪分区、神经血管与视神经的间距、眶尖接续、镜像及释放、选取高亮/隔离/剖切、完整取景、眶后切面保存与旧存档恢复；原有光路、神经信号、导览、测验及疾病回归通过。90 对新增或调整的中英文通过独立 LLM 审校。实际网格的离线投影检查了外形，这不等于浏览器 WebGL 渲染验收。本轮未做浏览器或真机检查，此前本地页面访问遭浏览器工具策略拒绝，未绕过限制。跨浏览器、触控、读屏、低端 GPU 及医学专家审核仍待完成，历史验证见功能清单。

React、TypeScript、Three.js、Zustand、Vite；模型、纹理和测试图由代码生成。轻量启动入口、界面和引擎分包；引擎包仍超过 500 kB，保留 Vite 提示。虹膜缓存保留约 1 MiB 私有像素，各模型的纹理与释放仍独立；原有虹膜纹理分辨率保留。
