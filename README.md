# eyesight

供医生进行眼球结构科普、常见眼病科普与互动演示的成人右眼 demo；眼病模块仍按清单逐步开发。React + TypeScript + Three.js + Zustand + Vite，纯前端运行。

## 运行

需要 Node.js 22.12+（22.x）、24.x 或 26+，以及 npm。本次验证环境：Node.js 26.5.0、npm 11.17.0。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认 http://127.0.0.1:5173 。开发服务只绑定本机。

```sh
npm test
npm run build
npm run preview
```

`dist/` 为已生成的静态网站，可放在静态 HTTP 服务上。不要直接双击 `index.html`：浏览器的模块加载需要 HTTP。

## 已实现

- 成人右眼：17 个可选择的组织、区域和空间，提供中英名称、拉丁名、作用、位置、知识提示与来源。
- 探索：旋转、缩放、四个视角、结构搜索、标签、显示/半透明/隐藏、隔离、分层展开。
- 剖切：矢状、水平、冠状三个切面与位置调节；壁层有截面环。直接点击模型保留切面与镜头；列表仅在目标被遮挡、裁去或离开画面时自动切换观察场景，支持撤销显露。
- 结构定位：按真实几何与可用视口聚焦，提供返回定位前视角、遮挡过滤标签、引导线、目标轮廓、眼底参照与固定解剖方位标。
- 搜索：支持中英文、拉丁名、结构 ID 和常见俗称；“黑眼珠”提示虹膜/瞳孔歧义，“眼底”返回分组，疾病词只展示相关结构。
- 光路与参数：保留正常聚焦、轴性近视、发散镜片矫正三个基准；支持眼轴、物距、调节、瞳孔及外镜片的单变量演示和自由组合。二维/三维共用追迹，显示截光、视网膜等效平面交点、离散程度及聚焦结论。
- 同条件对照：冻结参考参数，桌面双模型同步旋转/缩放，窄屏在同一视口切换参考/当前，显示参数差异；本地字形/条纹测试图表达交点离散带来的定性模糊。
- 生理演示：瞳孔、调节、光与神经信号可播放、暂停、单步与重播；信号演示也可从既有导览开启。光线与神经信号使用不同路径和图例。
- 三条短导览、共 11 步：从外到内、跟随光与神经信号、轴性近视。
- 六题结构识别：命名高亮结构、单次作答、揭晓不计分、反馈与结算。答题前隐藏名称标签和知识卡。
- 四个模式分别保存当前页面会话中的镜头、图层、剖切和参数；返回导览保留步骤，返回测验保留题序、答案与得分。
- 中英切换保留当前场景、导览与答题状态，仅语言偏好写入本地存储；不使用运行时翻译 API。
- 窄屏布局、键盘旋转/缩放、减少动画偏好、WebGL 初始化失败提示与上下文恢复重绘。

## 模型细节优化

- 角膜使用连续的非球面薄壳，内外缘分别衔接巩膜，增加平滑的表面高光。
- 虹膜使用确定性生成的颜色与凹凸纹理，表现放射纤维、虹膜卷缩轮附近的不规则纹理和周边收缩沟；瞳孔仍为几何开口。
- 晶状体改为前后不对称的双凸轮廓，加入位于囊膜内的核区，保留透明材质和结构选择。
- 视网膜增加柔和的眼底色泽，黄斑、中央凹及视盘贴附内壁；动静脉采用逐渐变细的分支和绕开中央凹的血管弓。

细节参考：[Webvision 视网膜解剖](https://www.webvision.pitt.edu/book/part-i-foundations/simple-anatomy-of-the-retina/)、[虹膜表面特征研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4736923/)。几何和纹理均由代码生成，没有新增外部模型、图片或运行依赖。

## 交互

鼠标移到可选择结构时显示手形并轻度提亮，点击后以蓝色持续高亮；空白处显示抓手，拖动时显示抓取状态。隐藏、半透明和被裁掉的部分不参与选择，测验中关闭悬停提示。拖动旋转，滚轮或加减按钮缩放。聚焦画布后可用方向键旋转、`+` / `-` 缩放。点击结构列表右侧圆点循环切换显示状态。

列表选择会将目标设为显示；已经可辨认的目标保留当前镜头与切面，只有显式“聚焦结构”或需要显露时才定位。自动显露后，“撤销显露”还原此前场景与镜头；“返回定位前视角”只还原镜头。单独查看时改选结构会跟随新目标，退出恢复进入隔离前的图层。

“重置视角”只恢复当前模式/步骤/题目的默认镜头；“重置场景”还原其场景参数，但保留导览步骤、答案、得分和语言。导览可用“重新开始本课”回到第一步；测验结算后的“再测一次”才会开始新一轮。点击品牌返回探索，切换模式或重复点击当前模式不会清空进度。

测验通过外形和位置识别高亮结构；其他组织保持半透明。选择答案立即提交，不允许修改本题答案。刷新页面会清除本次学习/测验进度，保留语言偏好。

光路面板的“演示方式”可选择一个变量并载入明确基准，其他控件锁定；调节以较近物体为起点，外镜片以延长眼轴为起点。“自由组合”保留当前参数并解锁全部控件；点击三个基准按钮可还原整组条件。调节与瞳孔会同步改变模型，连续滑块操作可一次撤销；切换语言和返回工作区保留参数。外镜片只按当前眼轴、远处平行光及放松调节求解，不随物距或调节自动对焦。

点击“保存为对照”后继续调节参数，可在相同镜头、观察条件与测试图下比较；“退出对照”保留当前参数。选择生理演示主题会结束对照并载入示例基准，演示期间锁定手动参数，退出后恢复原光学参数。切换模式会暂停播放；开启系统减少动画偏好后可继续阅读说明、单步和重置演示，不自动播放。

## 内容与模型边界

这是参数化教学示意，非患者扫描或医学级数字孪生。颜色、厚度、部分间距和小结构尺寸经过教学夸张；不涵盖微观层次、完整血管网络、眼外肌、眼睑和泪器。瞳孔作为真实开口，前后房作为空间表示。

透明组织采用透明度与高光近似；封闭眼球内使用简化遮光，展开、剖切或单独查看时恢复可读材质。浅层眼底凹陷并非完整组织学厚度模型。这些视觉优化不构成经过测量标定的折射、散射或临床成像模拟。

光路使用归一化的近轴薄透镜模型；调节上限按正常眼轴、较近物体的示例校准，不模拟真实生理幅度、像差或个人验光处方。轴性近视示例保持眼内屈光力不变并延长眼轴，不代表全部近视成因。实光线终止于视网膜等效平面，后方仅画虚线几何延长；交点不是弯曲网格上的真实落点。视神经传递的是神经信号。

测试图仅由模型的视网膜交点离散程度推导模糊，无有效样本时不显示清晰图像；不代表视力表结果，也不能代替未来眼病模块各自的散射或视野缺损示意。生理演示采用有限关键帧和固定讲解节奏，不模拟真实生理时间。

独立 LLM 已逐条审校中英术语与含义，详见 [翻译审校记录](docs/translation-review.md)。这不等于眼科专家审核，医学内容仍标记为待专家审校。

主要依据：[NEI 眼睛如何工作](https://www.nei.nih.gov/eye-health-information/healthy-vision/how-eyes-work)、[NEI 屈光不正](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/refractive-errors)、[NEI 近视](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/nearsightedness-myopia)。各结构的进一步来源见界面知识卡。
