# eyesight

供医生进行眼球结构科普、常见眼病科普与互动演示的纯前端应用。以成人眼球模型说明结构、成像与机制；短导览和理解确认按需使用。

![eyesight 交互预览](preview.png)

## 本地运行

需要 Node.js 22.12+（22.x）、24.x 或 26+，以及 npm。当前验证环境为 Node.js 26.5.0、npm 11.17.0。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`，开发服务仅绑定本机。

```sh
npm test -- --maxWorkers=1
npm run typecheck
npm run build
npm run preview
```

`dist/` 是生产静态文件，需通过 HTTP 服务访问；不能直接双击 `index.html`。预览默认地址为 `http://127.0.0.1:4173`。

## 当前功能

- **结构探索**：成人右眼、19 个组织/区域/空间，提供双语资料、搜索、定位、图层、隔离、关联观察、六种预设及三轴分层剖切。
- **眼球交互**：旋转缩放、悬停与选中反馈、固定解剖方位、目标轮廓、分层展开及场景撤销；桌面与窄屏布局。
- **光学演示**：正常聚焦、轴性近视、镜片矫正；眼轴、物距、调节、瞳孔、外镜片五类参数；二维/三维同源光路、同条件对照和定性测试图。
- **生理演示**：瞳孔、调节、光到神经信号，可播放、暂停、单步和重播。
- **四种常见眼病**：白内障混浊与散射、青光眼房水与损害、斜视双眼注视、弱视输入与视觉发育；正常/变化自由切换，说明与参数分别保存。
- **按需讲解辅助**：三条短导览、11 项可选操作、29 道理解确认题、独立会话及错题回顾，无完成门槛。
- **中英与恢复**：静态双语、独立 LLM 对照审校、版本化本地保存；语言切换保留参数、镜头、题序及答案。

完整操作、机制边界、验证与待办见 [《eyesight 功能进展与后续开发清单》](docs/development-status-2026-10-22.md)。

## 范围与待办

当前源码实现范围覆盖 T01—T13。T14 视网膜微观层级、T15 场景链接/PNG 导出/展示模式，以及外部眼部资产和眼外肌观察仍为可选待办。

这是参数化科普示意，几何、光学及疾病效果未经临床标定，不输出诊断、处方或疗效预测。独立 LLM 审校不等于医学专家审核；医学内容仍待专家审核。应用不采集患者资料，也没有账户或后端。

记录仅保存于当前浏览器；刷新后播放暂停，撤销栈与临时观察不恢复。清理浏览器存储会丢失本地记录。
