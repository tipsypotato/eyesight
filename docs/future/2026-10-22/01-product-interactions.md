# 01 · 产品体验与交互规格

状态：待实施。功能编号供任务和验收引用，不代表当前已支持。

## 1. 学习入口与信息架构

主导航按“结构探索 / 光学实验 / 短导览 / 识别测验 / 常见眼病”排列，对应 `explore / optics / tour / quiz / disease`。A、B 阶段保留现有四项，C 首次交付时才显示第五项。语言入口始终可见，显示“中文 / English”。

首次进入结构探索，显示简短提示：“先转动右眼，再选择一个结构。看不到内部时，试试分层剖切。”提供“观察完整眼球”和“从剖面开始”两个动作；后者沿用当前中心矢状剖面。提示完成后不重复遮挡模型，可从帮助重新打开。加载、无 WebGL、内容或本地保存失败各自说明当前可用能力，不用无限转圈。

桌面延续三栏：左侧负责“选什么”，中央负责“观察与操作”，右侧负责“是什么、为什么、下一步”。相同段落不在左右两栏重复。右侧详情采用名称、位置与功能、关系/任务、来源的顺序；默认展开前两项，详细来源按需展开。

## 2. 工作区状态契约（SYS-01）

### 2.1 切换与恢复

| 动作 | 必须发生 | 不应发生 |
| --- | --- | --- |
| 切换语言 | 当前及隐藏面板使用新语言；选项顺序保持 | 重建几何、镜头跳转、题目换序、重新计分 |
| 第一次进入一个模式 | 使用该模式的教学默认场景 | 把前一个模式的眼轴、病变材质或答案泄漏进来 |
| 返回已访问模式 | 恢复该模式的镜头、参数和进度草稿 | 调用当前 `setMode` 的整场景重置逻辑清空草稿 |
| 点击当前模式 | 无操作；导航焦点正常 | 再次开始一轮测验 |
| 离开模式 | 先保存草稿，取消该模式动画/拖动，撤销其临时材质与几何变化 | 旧异步回调在新模式覆盖相机或高亮 |
| “重置视角” | 仅恢复当前场景默认相机 | 重置剖切、参数、课程序号或答题 |
| “重置场景” | 恢复该模式默认几何显示、剖切、展开、标签及实验参数；保留学习记录 | 清空成绩、全局语言或其他模式草稿 |

每个模式拥有自己的场景草稿；语言是全局设置，不放进待恢复的场景快照。测验答案和课程进度属于学习记录，不放进“撤销场景”历史。疾病进入时记录来源模式；“返回原工作区”回到该模式及其草稿。点击任一主导航则直接进入被点模式，下一次进入疾病继续上次章节。

快速点击多个结构/课程时，最后一次操作生效。相机过渡、标签定位、材质更新必须可以取消或被新版本状态覆盖；切换模式后不得出现过期结果。工作区切换前结束尚未提交的滑块手势，以最后一个有效值保存。

### 2.2 恢复、撤销与本地存储（SYS-02）

“撤销”只管理最近 20 次当前工作区的场景操作：预设切换、图层更改、隔离、剖切、展开、参数更改。一段连续拖动只生成一个记录；镜头旋转、选中文字、语言切换、课程跳步和提交答案不进入记录。进入新课程步骤或疾病步骤时清空该工作区场景撤销栈，避免回到不匹配的教学状态。

按当前功能清单的 T07 范围，`eyesight.progress.v2` 保存经过校验的工作区场景草稿、实际镜头、导览位置/操作记录及测验会话/答案/顺序；刷新恢复已保存的场景与进度，动画暂停，撤销栈、临时关联观察及答后临时观察不恢复。疾病进度由后续章节接入。此规则替代归档时“刷新只恢复步骤默认场景”的限制。语言继续兼容已有 `eyesight.language`。数据带 `schemaVersion` 与 `contentVersion`：未知版本或无效字段丢弃对应部分，回到可操作默认值并提示一次。存储被禁用时仍可学习，当前页面内保留状态；不反复弹错。提供“清除本地学习记录”的明确二次操作；不建立账户或上传记录。

## 3. 结构探索

### 3.1 选择与智能定位（UX-01）

1. 点击模型时只高亮命中的可见结构并打开资料，保留用户镜头。重复点击同一目标不启动相机动画。
2. 从列表/搜索选择结构，保证目标非隐藏。目标已能辨认时保持视角；目标被完整眼球挡住时，先应用与结构匹配的观察预设，再定位。右上角显示“已切到眼底观察”等可撤销提示。
3. 资料卡提供“定位此结构”。中央凹、黄斑、视盘、悬韧带等小结构用目标包围球拟合镜头；目标占模型视口较短边约 20%—35%，同时保留至少一个邻近参照物。不能无限贴近或穿进网格。
4. 显示目标轮廓、名称引线及简短关系提示。中央凹示例：“位于黄斑中央；黄斑在视盘颞侧。”黄斑和视盘可同时标注，不能只靠颜色找位置。
5. 手动点击“定位”或自动显露导致视角改变后，出现“返回定位前视角”；一次返回精确恢复相机位置、朝向、target 和 zoom，不恢复旧语言或旧答案。用户后续拖动镜头不会自动跳回。
6. 当前被切面裁掉的目标须显露：列表选择应用对应预设；画布命中保持当前剖面。被隐藏/裁掉的几何不能隔空抢占命中。

复用 `CameraRig` 的包围球适配、球面插值及 reduced-motion；减少动画时直接到目标位置。默认过渡 400 ms，可被新操作中断。小结构不能仅放大空的 group 原点，应使用实际几何边界。

### 3.2 解剖方位与标签（UX-02）

视口常驻小方位轴/罗盘，明确“右眼 OD”；展示前/后、上/下、鼻/颞，随模型投影旋转，解剖含义不变。不能把“屏幕左”写成“鼻侧”。左眼上线后罗盘显示当前选中眼侧；双眼全景显示患者左右。

标签优先级：当前任务目标 > 当前选中 > 对比地标 > 其他开启标签。引线起点跟随表面；先做视锥、切面、隐藏和实际遮挡过滤，再做文字碰撞去重。目标被遮挡且允许内部观察时，出现一个“被遮挡，定位查看”提示，不把所有内部标签透出完整眼球。测验未作答时所有能泄露名称的场景标签、标题和无障碍名称均禁用。

图层按钮保留“显示 → 半透明 → 隐藏”顺序，提供文字提示与键盘名称；选中时不得只用一个低对比小圆点表达状态。半透明是观察辅助，默认不参与画布选取；可以从列表选中后变为显示。隐藏目标被重新选中时恢复显示。隔离时选下一个结构应跟随目标，退出隔离恢复进入前图层快照。

### 3.3 搜索（UX-03）

匹配当前语言、另一语言、拉丁名、结构 ID 和审核过的同义词；空查询恢复分组列表。清除搜索不清除选择。匹配到的结构沿用原有稳定 ID。

| 输入示例 | 结果规则 |
| --- | --- |
| 白眼球、眼白、sclera | 巩膜 |
| 晶体、crystalline lens | 晶状体；不与白内障疾病页面混成同一结果 |
| 黑眼珠 | 同时建议“虹膜（有颜色的环）”和“瞳孔（中央开口）”，标注“俗称含混，请选择” |
| 眼底 | 显示眼底分组入口；不是一个新增实体组织 |
| 白内障、glaucoma | C 上线后显示“常见眼病”类别结果；此前只提示相关结构，不显示不可用入口 |

## 4. 剖切与分层（UX-04）

### 4.1 命名预设

所有预设都从明确基准构造，不能继承上一个预设的隐藏项。除表中变化外：全部结构显示、无隔离、展开为 0、标签关闭，角膜和玻璃体半透明；空间仅用边界示意。选中目标若在该预设中隐藏，清除选择；否则保留。

| 预设 ID / 名称 | 相机与切面 | 重点层次 |
| --- | --- | --- |
| `intact` 完整眼球 | 斜向；关闭剖切 | 保持自然外观与外壳遮挡，内部结构不穿透显示 |
| `wall-cut` 眼球壁剖面 | 侧面；矢状面 x=0，保留 x≤0 | 看清巩膜→脉络膜→视网膜；前/后房和玻璃体半透明 |
| `anterior` 前段观察 | 斜向前部；矢状面 x=0，保留 x≤0 | 巩膜/脉络膜/视网膜半透明，睫状体/悬韧带/晶状体显示；后极地标与血管隐藏 |
| `fundus` 眼底观察 | 从前向后看眼底；关闭剖切 | 巩膜/脉络膜/角膜/虹膜/睫状体/悬韧带/晶状体及空间/玻璃体隐藏；视网膜半透明，黄斑/中央凹/视盘/视神经/血管显示 |
| `chambers` 眼内空间 | 侧面；矢状面 x=0，保留 x≤0 | 外壁半透明；前房、后房和玻璃体区域分别描边；腔隙不是实体色块 |
| `optical-path` 光路观察 | 侧面；矢状面 x=0，保留 x≤0 | 全部组织半透明，角膜/晶状体/视网膜保留清晰边界，开启光路；使用当前光学参数 |

`fundus` 相机需要避开前部残留遮挡，保留黄斑与视盘两个地标；不靠把视盘移到屏幕方便的位置实现。`optical-path` 在探索模式只显示当前默认/保存参数的光路，提供“进入光学实验”继续操作。

### 4.2 自由切面

轴向约定：矢状面 x=offset、水平面 y=offset、冠状面 z=offset；offset 范围 [-1,1]，沿用当前归一化眼球尺度。`keepSide='negative'` 表示保留该坐标≤offset，`positive` 反之。拖动镜头不能改变保留侧。

控制区顺序为“预设 → 切面开关 → 平面 → 位置 → 翻转保留侧 → 展开”。打开切面后显示细线平面框和方向箭头；拖动平面框与滑块同源，松手形成一次撤销记录。切面锁定默认开启，含义是锁定在眼球解剖坐标；首期只支持此方式，不能保留当前随相机自动翻侧的隐藏行为。后续如加入“跟随观察方向”，必须是独立且明确的开关。

展开与剖切可组合；切面和命中使用同一坐标体系，不能只裁渲染、不裁命中。关闭切面后，展开组织保持可见；展开归零且关闭切面时恢复完整眼球的内部遮挡。切换预设、退出光学或疾病后，恢复对应材质、法线/位置和标签，而非重复叠加变形。

## 5. 光学实验与基础生理

### 5.1 单变量实验（OPT-01）

第一屏保留“正常聚焦 / 轴性近视 / 镜片矫正”三个基准，默认展示“物体很远、正常眼轴、放松调节、无外镜片”。参数旁同时显示“改了什么”和“观察哪里”。每次拖动立即更新三维光线、二维光路、视网膜交点与一句结论，所有视图必须使用同一计算结果。

“实验”展开后一次只激活一个变量；其他变量锁在基准并说明。需要自由组合时显式切换“自由组合”，不把一个滑块背后偷偷联动多个成因。变量归零/恢复后应回到原基准，不因先前近视变形残留而改变角膜或眼底位置。

| 变量 | 首期控件与范围 | 连动规则与观察目标 |
| --- | --- | --- |
| 眼轴示意增量 | 连续 0—1；0 正常，1 对应现有 retinaZ=-1.22 | 保持角膜/晶状体屈光参数不变；视网膜后移；正常 retinaZ=-1；不是 mm |
| 物距 | “远处（平行入射）/较远/较近”三档 | 固定调节时近物需要更大屈光能力；数值只用于归一化模型，默认不显示米 |
| 调节 | 0—1，“放松→较强调节” | 连动睫状肌示意、悬韧带张力和晶状体曲率；不改变眼轴；在模型能力范围内近物重新聚焦 |
| 瞳孔 | “较小/中等/较大”三档 | 改变虹膜开口与通过的光束；不改变角膜/晶状体屈光力；不要把瞳孔等同自动对焦 |
| 外部镜片 | “无 / 为本示例求解的发散镜片” | 仅针对轴性近视示例启用自动矫正；不显示患者度数/通用近物处方 |

首期物距计算坐标以角膜前的物平面 z=4、z=2.5 作为较远/较近示例，远处使用平行入射；两档均在外镜片平面之前。调节能力上限按“正常眼轴+较近档可重新聚焦”校准，不自称真实生理调节幅度。瞳孔半径使用现有默认开口的 0.7/1/1.3 倍，网格与光束孔径一致；若几何约束不足，先修正开口边界，不能仅缩放整片虹膜造成悬韧带接缝错位。

焦点在无穷远或不能形成实焦点时，显示“当前模型内无有限实焦点”，不要画 NaN 坐标。光线只画到视网膜；需要表示其延长交点时用虚线延长辅助线并标“几何延长示意”，不让实线穿出眼后壁。

### 5.2 同条件对照与定性成像（OPT-02）

桌面“保存为对照”冻结当前参数；两侧使用相同视角、目标、光照和测试图，一边为“对照”，一边为“当前”。旋转、缩放同步；只有标明的参数可以不同。图例用线型与标签区分入射光、焦点和视网膜，不依赖红绿。退出对照恢复单视口和当前参数。

窄屏用同一个视口的“对照 / 当前”切换与固定差异摘要，避免两个过小视口。切换只换场景数据，镜头和测试图位置保持。斜视场景本来就是双眼，不额外显示四只小眼。

测试图采用本地生成的高对比字形/条纹图。定性清晰度由视网膜交点离散程度推导，并明确“模糊示意，不代表视力表结果”。正常失焦、晶状体散射、视野缺损采用不同的结果表示；不能共用一个“病情→高斯模糊”映射。无需摄像头、上传人脸或真实检查图片。

### 5.3 生理动作（PHY-01）

“光照与瞳孔”只演示较亮时缩小、较暗时扩大；不把任意 3D 光照强度映射为真实照度或瞳孔直径。开始播放后仍可暂停、单步、重播；切换模式立即停止。

“看远与看近”沿用 OPT-01 的光学计算。看近示例显示：睫状肌收缩 → 悬韧带张力减小 → 晶状体较凸 → 屈光能力增加。看远显示相反趋势。明确这是简化示意；暂不加入复杂眼外肌或全部近反射通路。

“光到神经信号”沿用现有 vision 导览：光到达视网膜后停止；使用不同颜色及脉冲/节点样式表示后续神经信号，由视网膜处理再经视神经传出。暂停时仍能从图例辨认两者。

## 6. 导览、操作任务与测验（EDU-01 / EDU-02）

每课开始展示一句学习目标、3—5 个步骤与预计操作；不承诺准确学习时长。现有三课优先复用，不另写一组平行课程。步骤包含“观察目标 + 一个小任务 + 解释”：例如眼球壁课要求从外向内选择三层；眼底课同时指示黄斑与视盘，并要求辨认鼻颞关系。

任务未完成时“继续观察”和“跳过操作”均可用；跳过记为已访问而非已掌握。任务达成给简短非遮挡反馈，可继续，不能每次成功自动把人送到下一屏。点击“上一步”回到该步骤的教学场景，不重写已经提交的测验答案。

末步主动作改为“练习本课”，直接生成与课程目标对应的 2—4 道题；次动作“回到探索”保留末步目标和观察场景。不要仅显示“可以去测验”的文字。

### 6.1 现有三课的首批任务与题目

保持 `anatomy / vision / myopia` 三个课程 ID 及 4/4/3 步结构。下面的操作任务是无分值的操作达成记录，不替代正式小测；完成与跳过分别保存。若步骤进入时已处于目标状态，仍需用户执行指定动作或点击“已观察”，不能仅由默认状态自动判定掌握。

| 课程/步骤（从 1 开始） | 操作任务与达成条件 |
| --- | --- |
| anatomy / 1 外部结构 | 点选巩膜，显示它与前部角膜连续的关系；目标选择事件记为达成 |
| anatomy / 2 眼球壁 | 按外到内依次选择巩膜→脉络膜→视网膜；错序给关系提示并允许重试，不扣分 |
| anatomy / 3 眼内空间 | 依次定位前房、后房、玻璃体区域；三个观察位均访问后达成，提示房水/凝胶区别 |
| anatomy / 4 眼底地标 | 同时标注黄斑和视盘，定位一次中央凹；点击“已观察鼻颞关系”达成 |
| vision / 1 光进入眼 | 暂停入射光示意，再定位瞳孔开口；两动作完成后达成 |
| vision / 2 共同聚焦 | 打开二维/三维同步表示，定位晶状体；说明角膜也参与折射，不把晶状体说成唯一屈光结构 |

### 6.2 会话与答题反馈

测验主入口第一次进入默认六道结构识别题，此后恢复最近进行的测验。课程练习按课程 ID 保存独立会话；点击“练习本课”时，未完成则继续，已完成则先显示结果与“新一轮练习”。新的课程练习不会覆盖其他未完成会话；提供题集选择返回基础识别或已开始的课程练习。疾病章内练习使用独立章节会话并原位展示，不强制离开疾病模式；共用题库和计分函数。每次返回都有明确的“回到本课/本章”动作。

题型按阶段加入：A 保持结构识别；B 增加相邻关系与基础机制；疾病阶段增加机制辨别。所有题目有稳定 `questionId`，结构只作为目标引用。选项随机一次后保存，切语言/离开回来/反馈展示不能重新打乱。

答题流程：未答 → 提交一个选项或“查看答案” → 锁定 → 展示反馈 → 点击下一题。提交后的点击不重复计分；查看答案计为“已看答案”，不计答对。反馈同时说明“正确是什么”和“为什么你的选择不符合题干”，并给一个“回到结构查看”入口。该入口保存测验，打开临时观察场景；“继续练习”回到原题的已答状态。

示例：目标巩膜而误选角膜，反馈为“巩膜是包绕大部分眼球的白色外层；角膜是前部透明区，与巩膜连续。可从透明/白色及前部/大部分外壁两点区分。”避免只重复巩膜定义，也不说误选者“完全没有保护作用”。

结果区区分“答对 / 答错 / 已看答案”，提供“复习错题”“重新练习本课”“回到探索”。错题包含答错和已看答案；已正确的题不混入首轮错题复习。新一轮使用新会话 ID，不覆盖历史记录；重开当前未完成测验需通过清晰的内联“放弃本轮并重开”动作确认。答题目标不得经页面标题、URL、隐藏详情、DOM data 属性或 ARIA 名称泄漏。

## 7. 移动端与可访问性（UX-05）

布局在可用宽度 <900 CSS px 时切到上下结构；<600 时使用底部面板。顶部保留模式条和语言；模式条单行横向滚动，选中项自动滚入可见区，不产生整页横向溢出。

模型区固定在工作区上部，底部面板使用“结构 / 参数 / 说明”标签，仅显示当前模式需要的标签。面板三档：收起（只见标题和关键动作）、半屏、全屏。模型在收起/半屏时保持可见；全屏显示“返回模型”。用按钮切换档位，拖拽手柄只是附加方式。键盘打开、横屏或高度 <600 CSS px 时允许普通页面滚动，以可操作为先，不能硬锁视口裁掉内容。

测验的“查看答案/下一题”、课程的“上一步/下一步”固定在面板底部安全区域，不跟随长反馈滚出屏幕。拖模型和拖面板区分命中区域；手指从参数控件起始时不能旋转模型。

交互触点至少 44×44 CSS px；正文与背景对比至少 4.5:1，关键非文字边界/焦点指示至少 3:1。Tab 顺序遵循模式→场景工具→面板，面板展开不制造焦点陷阱；Esc 关闭临时弹层并回到触发元素。所有滑块有名称、当前语义值与键盘操作。尊重减少动态效果；信息不能只由动画、颜色、悬停或精细拖拽传达。
