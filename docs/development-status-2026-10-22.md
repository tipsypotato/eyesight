| 功能 | 当前实现 | 与后续规划的区别 |
| --- | --- | --- |

| 解剖外观 | 连续非球面角膜薄壳；虹膜放射纤维、卷缩轮和收缩沟程序纹理；真实瞳孔开口；前后不对称双凸晶状体及核区；贴合内壁的黄斑、中央凹、视盘与分支血管 | 参数化教学示意，未由患者扫描或眼科专家标定 |
| 基础观察 | 四个视角、显示/半透明/隐藏、结构隔离、名称标签、分层展开；矢状/水平/冠状三种自由剖切与位置滑块 | 当前三平面不等于 T03 的六个命名预设；显式保留侧及通用撤销尚未交付 |
| 基础光路 | 正常聚焦、轴性近视、发散镜片矫正三个示例；二维/三维使用同一计算结果，近视示例延长后半球，退出后还原 | 尚无物距、调节、瞳孔单变量实验或同条件双视图对照 |
| 短导览 | 从外到内、光与神经信号、轴性近视三课，共 11 步；目标结构与说明随步骤更新 | 仍以观察讲解为主；未接入操作达成、课程题集、错题复习 |
| 结构测验 | 六题结构识别，随机题序；单次提交、揭晓不计分、答案锁定、反馈与结算 | 仍使用原六题，不包含规划中的课程九题或疾病题目 |
| 中英文 | 静态双语内容；语言切换保留场景与学习状态；既有内容有独立 LLM 对照审校记录 | 不使用运行时翻译 API；LLM 审校不等于医学专家审核 |

17 个对象涵盖角膜、巩膜、脉络膜、视网膜、虹膜、瞳孔、睫状体、晶状体悬韧带、晶状体、前房、后房、玻璃体、黄斑、中央凹、视盘、视神经和视网膜血管。瞳孔作为开口，前后房作为空间，黄斑/中央凹作为视网膜区域表达。

## 3. 本轮实现：T02 结构查找与观察

以下能力已接入当前代码并完成自动检查及本地浏览器复验：

| 能力 | 本轮具体实现 |
| --- | --- |
| 区分选择与定位 | 画布普通选择保留镜头和切面；列表/搜索先判断目标可见性，可见目标保持当前视角，遮挡或裁掉目标使用对应显露场景再定位 |
| 可恢复的显露 | 显示已切换的观察场景提示，可撤销显露；手动定位或自动显露后可返回定位前镜头，保留最新语言和答案 |
| 小结构定位 | 根据实际网格边界拟合，眼底/视神经采用对应观察方向；定位过渡改为 400ms，并保留中断和减少动画机制 |
| 可用视口 | 测量画布内覆盖控件，使用可用区域拟合和投影偏移；相机快照包含投影偏移，避免返回镜头时偏移丢失 |
| 标签与参照 | 依据实际可见表面、切面及遮挡过滤标签；选中目标优先，眼底地标作为参照；提供引线、选中范围辅助和遮挡定位入口 |
| 解剖方位 | 常驻右眼 OD 方位罗盘；前/后、上/下、鼻/颞随相机投影更新，保持右眼的解剖坐标语义 |
| 隔离恢复 | 隔离中切换目标继续观察，退出隔离恢复进入前图层快照 |
| 搜索扩充 | 支持中英、拉丁名、稳定 ID 和同义词；白眼球/眼白→巩膜，晶体→晶状体；黑眼珠同时提示虹膜/瞳孔及歧义；眼底对应分组；白内障/青光眼只提示相关结构，不提供未实现的疾病入口 |
| 测验边界 | 测验中关闭额外定位和名称标签，避免新观察辅助泄露答案；沿用原单次作答规则 |

眼底参照是结构关系的第一步，**尚不是可进入、切换成员并返回的完整“教学组合”系统**。自动显露所需场景也不等于 T03 的完整命名预设工具栏。
