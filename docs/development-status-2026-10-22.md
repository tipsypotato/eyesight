# eyesight 功能进展与后续开发清单

更新日期：2026-10-22。eyesight 是供医生进行眼球结构科普、常见眼病科普与互动演示的纯前端工具。医生是直接操作者，患者及公众是主要讲解受众。

当前源码实现范围覆盖 T01—T13；本轮最终验证结果见本文“验证范围”。T14、T15 及外部资产增强保持可选待办。运行方法见 [README](../README.md)。

## 使用定位

医生可以直接进入需要的结构或眼病主题，指认位置、调整模型、比较正常与变化，再配合简明说明完成讲解。主题和环节可以自由切换，无需按课程顺序推进。

短导览、可选观察操作和理解确认题是按需辅助，不设置完成门槛；不以课程完成率或测验分数作为核心体验标准。

## 眼球结构与观察

模型以成人右眼为基础，左眼用于斜视和弱视双眼场景。19 个可选对象按四组组织：

| 分组 | 可选对象 |
| --- | --- |
| 眼球壁 | 角膜、巩膜、脉络膜、视网膜 |
| 前段结构 | 虹膜、瞳孔、睫状体、晶状体悬韧带、晶状体、房角、小梁网 |
| 眼房与玻璃体 | 前房、后房、玻璃体 |
| 眼底与视神经 | 黄斑、中央凹、视盘、视神经、视网膜血管 |

资料提供中英名称、拉丁名、位置、作用、知识提示和来源。瞳孔是开口，前后房是空间，房角及黄斑/中央凹是区域；它们不会被统一描述成独立实体组织。

角膜采用连续非球面薄壳与高光；虹膜以程序纹理表现放射纤维、卷缩轮和收缩沟，并保留真实瞳孔开口。晶状体采用前后不对称双凸轮廓及内部核区；眼底地标与分支血管贴合视网膜内壁。

- 拖动模型旋转，滚轮或加减按钮缩放；聚焦画布后可用方向键旋转、`+` / `-` 缩放。四个视角按钮提供斜向、前视、侧视、后视。
- 可选结构悬停显示手形与轻度提亮；点击后持续高亮，保留当前镜头和切面。空白处显示抓手，拖动显示抓取状态；拖动不当作点击。
- 列表圆点循环切换显示、半透明、隐藏。半透明及隐藏结构不参与画布选取；从列表选择时恢复目标显示。
- 列表/搜索选择可见目标时保留镜头；目标被遮挡、裁掉或移出画面时切换显露场景并定位。可撤销显露，或只返回定位前镜头。
- 单独查看时改选结构会跟随新目标，退出后恢复之前的图层。小结构按实际几何边界定位，提供轮廓、名称引线和邻近地标。
- 搜索支持中英文、拉丁名、结构 ID 和俗称；“黑眼珠”提示虹膜/瞳孔歧义，“眼底”返回分组。疾病词搜索当前返回相关结构，疾病章节从“常见眼病”进入。

六种观察预设为完整眼球、眼球壁剖面、前段、眼底、眼内空间和光路；每次从明确图层基准重建。眼内空间用边界表达前后房及玻璃体区域，眼底保留黄斑与视盘参照。

自由剖切支持矢状、水平、冠状三轴、位置滑块、拖动平面框及翻转保留侧。切面固定在眼球坐标中，旋转镜头不会改变保留侧；可与分层展开组合。通用观察工作区保留最近 20 条场景撤销，一次连续调节记为一次操作，答案与语言不随撤销倒退。

关联观察包括调节、房水相关结构、眼底地标三组。成员使用次级轮廓与标签，支持联合取景、切换成员和返回原场景；完整房水流出机制在青光眼章节展示。

## 光路、对照与生理演示

“基础光路”提供正常聚焦、轴性近视、镜片矫正三个基准。二维示意与三维光线读取同一追迹结果，显示瞳孔截光、视网膜等效平面交点、有效样本数、离散程度及聚焦结论。

| 控制项 | 演示内容 |
| --- | --- |
| 眼轴示意增量 | 在屈光基准不变时延长后部眼球，观察焦点与视网膜关系 |
| 物距 | 远处平行入射、较远、较近三档 |
| 调节 | 联动晶状体曲率、睫状体与悬韧带示意 |
| 瞳孔 | 较小、中等、较大三档；开口几何与光束孔径一致 |
| 外部镜片 | 按该示例眼轴、远物与放松调节条件求解的发散镜片 |

选择单变量演示会载入明确基准并锁定其他变量；“自由组合”保留当前参数并解锁。没有有限实焦点、焦点在图外或无有效光线样本时分别说明，不显示无效坐标或虚假的清晰结果。

“保存为对照”冻结参考参数。桌面显示同步旋转/缩放的两模型，窄屏在同一视口切换参考与当前，并保留参数差异摘要。退出对照保留当前参数。本地字形/条纹测试图以交点离散程度表达定性模糊。

生理演示提供瞳孔、调节、光到神经信号三组关键帧，可播放、暂停、单步、重播与退出。光线止于视网膜；转换节点和紫色虚线另行表示经视盘、视神经传出的神经信息。切换模式停止播放，减少动画偏好下仍可单步阅读；退出演示恢复此前光学参数。

## 常见眼病科普

从主导航“常见眼病”进入，首次显示白内障的正常参考。四章共用“正常结构 → 发生什么变化 → 功能会怎样受影响 → 理解确认（可选）”，任何环节均可直接进入，不要求答题后才能继续演示。

当前病种、眼侧、正常/变化状态常驻。正常参考不删除变化参数；再次进入某章恢复该章步骤、参数、镜头与答题。相关结构通过临时资料层查看，关闭后继续本章；“返回原工作区”恢复进入前的模式与草稿。

单眼章节在桌面可同时比较正常与变化，窄屏共用一个视口；斜视和弱视始终显示同一对眼。重置本章只重新演示，保留理解确认记录。

### 白内障

- 成人右眼前段场景，保留角膜、虹膜、睫状体和悬韧带的邻近关系；可切换晶状体局部与眼球内位置。
- 混浊强度为 0—1 的显示参数，只改变晶状体与核区外观，不改变角膜、瞳孔开口、眼轴或晶状体几何。
- 本地对比图展示雾感与对比度下降，点光源场景展示光晕。正常参考保持清晰，变化预览使用当前混浊参数。
- 本章固定屈光参数以单独说明透光与散射；现实白内障可能伴随屈光变化，该部分未模拟。配套 3 题帮助区分晶状体混浊、角膜病变与单纯失焦。

### 青光眼

- 新增房角区域及小梁网组织，接入结构资料与搜索；提供房水流出、眼底与视神经两种观察位。
- 青绿色箭头沿睫状突、后房、瞳孔、前房、房角小梁网排列，可播放或暂停；静态箭头在减少动画时仍保留。
- 四个独立情景为正常参考、流出受限风险、已有损害、正常眼压损害；它们不是病程阶段，也不计算眼压或损伤百分比。
- 神经纤维的连续/中断差异与可能的局部视野缺损分别表达。改善流出保留已有损害和缺损；正常眼压情景也可单独显示损害。
- 始终保留早期可能无明显自觉症状的说明；视野图用局部斜线区域举例，不以闭合黑边模拟所有人的视野。配套 4 题区分风险、诊断与损害。

### 斜视与双眼

- 左右眼为独立几何与材质实例，左眼地标按鼻颞关系镜像构建并处理三角绕序；点击、高亮、标签及方位标区分 OD/OS。
- 双眼共同指向近/远目标，正常看近时会聚；不能以两条方向线不平行直接判断内斜。
- 内斜、外斜及自定偏差作用于指定眼侧；额外水平偏差范围为 −20° 至 +20°，正值鼻侧、负值颞侧，仅为几何示意。
- 可分别讲解眼位、成人可能复视、儿童可能抑制，明确这些体验并非每位患者必然出现。提供进入弱视机制的链接及 3 道配套题。

### 弱视

- 用成人双眼几何与“输入 → 视觉处理”图说明儿童视觉发育机制；不把成人模型称为儿童眼球。
- 三类原因分别为屈光参差、斜视相关、视觉输入受限。每类独立保留原因/异常输入/发育结果卡片位置和输入改善开关。
- 屈光参差复用正常与轴性近视基准；改善输入通过镜片与共享追迹表达，保持原眼轴。斜视案例改善眼位，输入受限案例解除示意混浊。
- 所有输入改善均保留已经形成的发育结果，避免暗示视功能即时恢复。默认仅演示右眼输入差异，同时说明弱视也可能影响双眼；配套 4 题。

## 短导览与理解确认

三条短导览为从外到内、光与神经信号、轴性近视，共 11 步及 11 项可选观察操作。可跳过，完成操作后由医生决定下一步；末步可进入对应题集或带着场景返回探索。

29 道题包括 6 道结构识别、9 道导览配套题和 14 道眼病题（白内障 3、青光眼 4、斜视 3、弱视 4）。各主题使用同一答题机制，但会话、顺序、答案与历史记录独立。

提交答案后锁定本题；查看答案单独记录，不计作答对。反馈解释正确项和误选原因，可查看相关结构后继续；错题回顾仅纳入答错及已揭晓题。未完成时新开一轮需内联确认，旧记录仍保留。未作答时隐藏会泄露答案的结构名称和目标提示。

## 状态保存、语言与设备操作

结构探索、光学实验、短导览、识别测验、常见眼病共五个工作区分别保存草稿。重复点击当前模式不重开场景或测验；切换语言保留镜头、参数、步骤、题序和答案。

| 操作 | 保留与恢复范围 |
| --- | --- |
| 重置视角 | 恢复当前场景默认镜头，保留参数与记录 |
| 重置场景/本章示意 | 还原当前场景参数，保留其他工作区、语言和答题记录 |
| 刷新页面 | 恢复合法场景、镜头、导览记录、各章参数与测验会话；播放暂停 |
| 清除本地记录 | 明确二次操作后清除场景和进度，保留语言偏好 |

记录保存在当前浏览器的 `eyesight.progress.v2`，语言为 `eyesight.language`，没有账户或跨设备同步。损坏模块局部降级；未知内容版本保留合法场景并丢弃不兼容记录，显示提示。存储不可用时仍可在当前页面操作。撤销栈、临时观察与疾病对照开关不随刷新恢复；光学工作区的已存对照参数随草稿保存。清理浏览器存储后没有服务端备份。

桌面采用三栏；小于 900 CSS px 使用模型与操作面板上下布局，提供收起、半屏、全屏及返回模型。固定底部动作让长说明中的前后环节与答题动作仍可达。支持键盘面板切换、焦点恢复、减少动画偏好及 WebGL 失败提示/上下文恢复。

## 内容依据与示意边界

中英文采用静态内容；本轮新增及变更的 257 对中英文已通过独立 LLM 对照审校（疾病说明 136、题目 98、通用文案 11、新结构 10、画布辅助说明 1、页面简介 1），核对术语、眼侧、条件、否定关系和操作含义；不调用运行时翻译 API。LLM 一致性检查不等于医学专家审核，当前医学内容仍为待专家审核。

| 弱视 | [NEI · Amblyopia](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/amblyopia-lazy-eye)、[AAPOS · Amblyopia](https://aapos.org/glossary/amblyopia) |

各结构和眼病界面还提供对应来源卡。部分 NCBI 页面在本轮访问中遇到验证页；不能据此声称完成全文医学核验。模型与图示均由本项目代码生成，来源链接不代表复制其图片或模型。

- 解剖为参数化科普模型，颜色、厚度、间距和小结构尺寸有展示性调整，未经患者扫描或临床尺寸标定；尚无完整组织学、眼外肌、眼睑、泪器与全部血管网络。
- 透明度、高光、内部遮光及混浊为显示近似；光学采用归一化近轴模型及视网膜等效平面，不模拟完整像差或真实曲面交点。
- 测试图、散射、视野图和双眼输入图分别说明不同机制，不是视力检查、患者实际主观视觉或疗效预测；动画节奏不是生理时间标定。
- 模型不输出诊断、风险评分、疾病分期、验光处方、用药/遮盖时长或手术操作建议；软件重置不表示临床恢复。
