# eyesight 功能进展与后续开发清单

更新日期：2026-10-24。eyesight 是供医生进行眼球结构科普、常见眼病科普与互动演示的纯前端工具。医生是直接操作者，患者及公众是主要讲解受众。

当前源码实现范围覆盖 T01—T13、六条眼外肌、结膜/眼睑及眼眶静态观察、头骨位置参照、加大分层与平铺；本轮最终验证结果见本文“验证范围”。T14、T15 及外部资产增强保持可选待办。运行方法见 [README](../README.md)。

## 使用定位

医生可以直接进入需要的结构或眼病主题，指认位置、调整模型、比较正常与变化，再配合简明说明完成讲解。主题和环节可以自由切换，无需按课程顺序推进。

短导览、可选观察操作和理解确认题是按需辅助，不设置完成门槛；不以课程完成率或测验分数作为核心体验标准。

## 眼球结构与观察

模型以成人右眼为基础，左眼用于斜视和弱视双眼场景。51 个可选对象按七组组织：

| 分组 | 可选对象 |
| --- | --- |
| 眼球壁 | 角膜、巩膜、脉络膜、视网膜 |
| 前段结构 | 虹膜、瞳孔、睫状体、晶状体悬韧带、晶状体、房角、小梁网 |
| 眼房与玻璃体 | 前房、后房、玻璃体 |
| 眼底与视神经 | 黄斑、中央凹、视盘、视神经、视网膜血管 |
| 眼外肌 | 上直肌、下直肌、内直肌、外直肌、上斜肌、下斜肌 |
| 结膜与眼睑 | 球结膜、睑结膜、眼睑皮肤、眼轮匝肌、提上睑肌、睑板、睑板腺、Zeis 腺、Moll 腺 |
| 眼眶与内容物 | 眶上壁、眶下壁、眶内侧壁、眶外侧壁、肌锥内脂肪、肌锥外脂肪、动眼神经、滑车神经、展神经、额神经、泪腺神经、鼻睫神经、睫状神经节、眼动脉、眼上静脉、眼下静脉、泪腺 |

资料提供中英名称、拉丁名、位置、作用、知识提示和来源。瞳孔是开口，前后房是空间，房角及黄斑/中央凹是区域；它们不会被统一描述成独立实体组织。

角膜采用连续非球面薄壳与高光；虹膜以程序纹理表现放射纤维、卷缩轮和收缩沟，并保留真实瞳孔开口。晶状体采用前后不对称双凸轮廓及内部核区；眼底地标与分支血管贴合视网膜内壁。

- 拖动模型旋转，滚轮或加减按钮缩放；聚焦画布后可用方向键旋转、`+` / `-` 缩放。四个视角按钮提供斜向、前视、侧视、后视。
- 可选结构悬停显示手形与轻度提亮；点击后持续高亮，保留当前镜头和切面。空白处显示抓手，拖动显示抓取状态；拖动不当作点击。
- 列表圆点循环切换显示、半透明、隐藏。半透明及隐藏结构不参与画布选取；从列表选择时恢复目标显示。
- 列表/搜索选择可见目标时保留镜头；目标被遮挡、裁掉或移出画面时切换显露场景并定位。可撤销显露，或只返回定位前镜头。
- 单独查看时改选结构会跟随新目标，退出后恢复之前的图层。小结构按实际几何边界定位，提供材质高亮、名称引线和邻近地标；选中目标不再显示外围虚线圈。
- 搜索支持中英文、拉丁名、结构 ID 和俗称；“黑眼珠”提示虹膜/瞳孔歧义，“眼底”返回分组。疾病词搜索当前返回相关结构，疾病章节从“常见眼病”进入。

十种观察预设按“整体 → 外围组织 → 眼球内部 → 光路”排序：全部结构、眼眶与内容物、结膜与眼睑、眼外肌观察、完整眼球、眼球壁剖面、前段观察、眼内空间、眼底观察、光路观察。每次从明确图层基准重建；眼内空间用边界表达前后房及玻璃体区域，眼底保留黄斑与视盘参照。

“全部结构”是解剖探索的新默认：51 个结构图层均为显示，关闭剖切与分离，开启头骨位置参照并采用斜向整体取景；重置场景和清空本地记录后也回到该状态。已有存档继续恢复用户保存的图层、剖切和镜头，不强制覆盖；选择首项“全部结构”可手动切回。旧记录缺少头骨开关时保持关闭，不改变旧镜头。内部结构仍会被外层遮挡，使用剖切、分层/平铺或专门预设细看。

全部结构预设仅用于解剖探索，原有九个预设的组织范围不变，光学、短导览、理解确认和疾病场景保留原来的显示基准。切换预设、撤销、隔离、工作区恢复与中英文继续沿用已有交互；存档格式无需迁移。

自由剖切支持矢状、水平、冠状三轴、位置滑块、拖动平面框及翻转保留侧。切面固定在眼球坐标中，旋转镜头不会改变保留侧；可与分层展开组合。通用观察工作区保留最近 20 条场景撤销，一次连续调节记为一次操作，答案与语言不随撤销倒退。

关联观察包括调节、房水相关结构、眼底地标三组。未选中的关联成员保留次级轮廓与标签，选中成员使用材质高亮与名称引线，支持联合取景、切换成员和返回原场景；完整房水流出机制在青光眼章节展示。

### 解剖探索控件布局（2026-10-24）

- 移除选中结构外围的虚线圈，保留悬停、点击高亮、名称引线、邻近地标及遮挡目标的定位入口。
- 观察预设默认收起，摘要显示当前预设或“自定义视图”；展开后可选择上述十种预设。选择后自动收起并将焦点返回摘要，Escape 可关闭展开菜单。
- 视角、缩放与撤销集中到紧凑工具区，按宽度换行。剖切与分层滑块在空间足够时并排，窄屏上下排列；剖切轴向、翻转、保留侧数值，以及分层/平铺阶段、百分比与分界线持续可见。
- 长操作说明默认折叠，可按需展开；光路入口及平铺暂隐三维光路的状态提示继续显示。按钮、菜单摘要及滑块保留至少 44px 的操作高度，支持键盘和中英切换。
- 调整只应用于解剖探索控件排布，其他工作区保留原布局。手机沿用整页滚动与“操作模型”开关，不新增内部滚动区。

### 分层展开与平铺（2026-10-24）

- 分层滑块仍为 0–100%。前两个三分之一区间沿原来的方向展开，最大距离约为旧版的 3 倍；达到最右侧三分之一区间（滑块 67% 起）切换平铺，继续右拉增大格间距。滑块显示阶段、百分比及分界线，并提供中英文与读屏说明。
- 平铺只排列当前显示及半透明的结构，隐藏项保持隐藏；按实际几何尺寸和深度余量分格，保留模型比例、朝向与立体形状。进入平铺切换前视并自动取景，后续仍可旋转、缩放和切换视角；前视用于逐项并列观察。隐藏图层、增加结构或单独查看后重新排列。
- 保留选取、高亮、标签、定位、隔离和场景撤销。从列表显露被隐藏、裁掉或移出镜头的目标时保留平铺，临时关闭剖切以完整显露；可撤销显露。一次连续拖动只记一条撤销，跨越分界后自动前视也纳入场景记录。
- 平铺中按每个结构原来的解剖坐标应用剖切，轴向、位置滑块及保留侧翻转仍可用；不显示跨网格的平面拖动框。回到分层区域后恢复整体固定切面和拖框。分离时剖切范围与框体同步扩展，覆盖展开后的角膜、眼睑和眶部。
- 平铺时暂隐三维光路与神经信号叠加，避免将原位光路画在互相分开的格位之间；参数、二维光学图和演示状态保留，退出平铺后恢复三维叠加。
- 工作区切换与刷新恢复平铺值、图层和实际镜头。旧版分离值按新的距离倍率换算，保留原来的展开外观和镜头，不会把旧场景直接切成平铺；新记录保存当前交互版本，无需清空本地数据。

本地记录升级为格式 v3，继续使用原存储键以读取旧记录。如需回退到旧程序，先备份 localStorage 中的 `eyesight.progress.v2` 项；旧程序不识别 v3 格式。

平铺是观察排布，不代表真实空间位置；自由旋转后可能出现透视重叠，可用前视恢复并列观察。大量结构同时显示时小结构仍可通过定位和缩放细看，未另加组织缩放或新交互模式。

### 眼外肌（2026-10-23）

六肌采用程序生成的扁带状肌腹、纵向纤维和浅色肌腱。四直肌从眶尖方向走向赤道前巩膜；上斜肌在上鼻侧经过滑车折返，止于后颞侧；下斜肌从前鼻下方绕向后颞下方。滑车作为上斜肌的附属参照显示，六肌可分别选取。

- 在解剖探索中点击“眼外肌观察”或“完整眼球”显示六肌；从其他结构预设切入时自动重建显示基准。光路、导览、原有识别题和四章眼病默认隐藏眼外肌，保持原有观察目标。光学工作区不提供眼外肌预设，其“完整眼球”也隐藏六肌，避免正常静态附着与眼轴变化混用。
- 搜索支持眼外肌/EOM 分组，以及中英名称、拉丁名和 SR/IR/MR/LR/SO/IO 精确缩写。资料说明第一眼位的作用与神经支配，鼻颞含义不由屏幕左右决定。
- 复用悬停手形、点击高亮、名称引线、显示/半透明/隐藏、单独查看、分层展开和三轴剖切。肌肉被裁切或遮挡时可定位显露，以半透明巩膜作参照，并撤销回原场景。
- 取景按实际可见结构计算，完整容纳肌肉走行；隐藏肌肉不拉远光路或双眼场景。长肌肉聚焦使用独立取景比例，避免套用小结构缩放后难以辨识。
- 六肌和滑车沿用左右眼镜像与独立资源管理；双眼注视场景默认隐藏静态肌肉。肌肉及标签不随眼轴参数后伸；未建立眶部固定起点、收缩变形、肌力和眼位之间的动态模型。
- 语言、选中结构、图层、隔离、剖切及展开值沿用工作区和刷新恢复。旧记录缺少六肌时补为隐藏，包含隔离前图层；保留原镜头、场景、导览与答题记录，不要求清空存储。

肌肉的尺寸、厚度、间距与肌腱长度用于科普辨识，尚未临床标定；肌肉剖切沿用表面裁切，不额外生成组织学切面或实体封口。本轮不新增导览和题库主题。

### 结膜与眼睑（2026-10-24）

在“解剖探索”中选择“结膜与眼睑”，查看上下睑与前部眼球的关系。球结膜覆盖前部巩膜并止于角膜缘，睑结膜衬覆眼睑内面，经穹隆反折与球结膜连续；角膜中央保持开放。

- 上下睑显示皮肤、睫毛参照、眼轮匝肌、睑板和睑结膜。提上睑肌及腱膜只连接上睑。睑板内排列睑板腺，睫毛根附近区分 Zeis 皮脂腺与 Moll 顶泌汗腺。
- 专用预设将皮肤、眼轮匝肌、睑板设为半透明，以便观察内部；保留视网膜、脉络膜后壁，避免瞳孔开口直接透见白色巩膜。可从结构列表切换显示/半透明/隐藏，或选取单项、单独查看、分层展开及三轴剖切。睫毛随皮肤图层显示；上下睑中的同名组织作为一个可选对象。
- 搜索支持中英名称、拉丁名，以及“结膜”“眼睑”、MGD、Zeis/Moll 等别称。MGD 仅定位睑板腺资料，不新增疾病章节或诊断功能。
- 新组织接入悬停、选中高亮、定位、名称标签、剖切、展开、撤销及刷新恢复。被遮挡时显露目标，并保留半透明的相邻眼睑/结膜及前眼表面作参照。
- 原有观察预设、基础光路、短导览、理解确认和疾病场景默认隐藏新增组织，继续观察原来的目标；旧记录缺少新图层时补为隐藏，保留已有场景、隔离前图层和答题记录。手机仍默认滚页，进入“操作模型”后使用模型手势。

结膜与眼睑是静态结构示意，组织厚度、颜色、腺体数量和间距为辨识作了简化，未经临床标定；未模拟眨眼、腺体分泌、泪膜动力学，也未补齐眶隔、Müller 肌、下睑缩肌或完整泪器。眶脂肪与泪腺在后续眼眶增补中加入，见下节。剖切显示表面裁切，不生成眼睑组织学切面封口。

视神经主干已改为平滑圆截面的管体，保留原有走行、视盘连接、神经信号演示、选取和剖切；不再沿用六边形截面。

### 眼眶与内容物（2026-10-24）

在“解剖探索”中选择“眼眶与内容物”，同时观察骨性眼眶、眼球及周围组织。新增 17 个可选对象；眼球、视神经、六条眼外肌和提上睑肌直接复用已有模型，不重复计数。

- 眶上壁、下壁、内侧壁和外侧壁分别选取，形成前方开放、后方收敛并留有开口的骨性轮廓；位置与鼻颞方向沿用成人右眼坐标。骨壁构成写入双语资料，未将七块骨分别建模。
- 眶脂肪分为肌锥内、肌锥外两组，以有限分叶体块表达眼球后方、肌锥和骨壁之间的关系。体块不是独立解剖包膜，也不是实际脂肪体积测量。
- 神经显示动眼神经（III）、滑车神经（IV）、展神经（VI）、V1 的额神经/泪腺神经/鼻睫神经，以及睫状神经节；与已有视神经区分功能。血管显示眼动脉及眼上、眼下静脉的主干与代表性分支；泪腺位于前上颞侧，与眼睑的睑板腺分别说明。
- 同一视神经主干接续到眶尖后口，保留原有控制点、48 段圆截面和末端封口；神经信号路径跟随延长后的几何，取景包含完整后段。
- 专用预设的四面眶壁与两组脂肪为半透明，内部眼球、眼外肌、提上睑肌及主要神经血管显示。可逐层切换、选取高亮、定位、单独查看、三轴剖切、分层展开及撤销；眼眶可见时自动适配取景和剖切框，位置范围扩至眶尖，展开时继续扩展。原有眼球场景保留原来的剖切尺度。
- 搜索“眼眶 / orbit / 眶内容物”返回新增分组；“眶壁”“眶脂肪”、V1、CN II/III/IV/VI、SOV/IOV 可定位对应结构或子集。眼球、眼外肌、视神经和提上睑肌仍在原分组中，完整关系通过专用预设查看。
