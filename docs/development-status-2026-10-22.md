# eyesight 功能进展与后续开发清单

更新日期：2026-10-31。eyesight 是供医生进行眼球结构科普、常见眼病科普与互动演示的纯前端工具。医生是直接操作者，患者及公众是主要讲解受众。

本文集中说明当前功能、操作方式、示意边界与待办。运行、构建和发布方法见 [README](../README.md)，维护与提交规则见 [AGENTS.md](../AGENTS.md)。

## 使用定位

医生可以直接进入需要的结构或眼病主题，指认位置、调整模型、比较正常与变化，再配合简明说明完成讲解。主题和环节可以自由切换，无需按课程顺序推进。

短导览、可选观察操作和理解确认题是按需辅助，不设置完成门槛；不以课程完成率或测验分数作为核心体验标准。

## 眼球结构与观察

模型以成人右眼为基础，左眼用于斜视和弱视双眼场景。51 个可选对象按七组组织：

| 分组 | 可选对象 |
| --- | --- |
| 眼球壁 | 角膜、巩膜、脉络膜、视网膜 |
| 前段结构 | 虹膜、瞳孔、睫状体、晶状体悬韧带、晶状体、房角、小梁网 |
| 眼房与玻璃体 | 前房、后房、玻璃体 |
| 眼底与视神经 | 黄斑、中央凹、视盘、视神经、视网膜血管 |
| 眼外肌 | 上直肌、下直肌、内直肌、外直肌、上斜肌、下斜肌 |
| 结膜与眼睑 | 球结膜、睑结膜、眼睑皮肤、眼轮匝肌、提上睑肌、睑板、睑板腺、Zeis 腺、Moll 腺 |
| 眼眶与内容物 | 眶上壁、眶下壁、眶内侧壁、眶外侧壁、肌锥内脂肪、肌锥外脂肪、动眼神经、滑车神经、展神经、额神经、泪腺神经、鼻睫神经、睫状神经节、眼动脉、眼上静脉、眼下静脉、泪腺 |

资料提供中英名称、拉丁名、位置、作用、知识提示和来源。瞳孔是开口，前后房是空间，房角及黄斑/中央凹是区域；它们不会被统一描述成独立实体组织。

角膜采用连续非球面薄壳与高光；虹膜以程序纹理表现放射纤维、卷缩轮和收缩沟，并保留真实瞳孔开口。晶状体采用前后不对称双凸轮廓及内部核区；眼底地标与分支血管贴合视网膜内壁。

玻璃体表现为具有连续外周皮质的凝胶体：前部周边平滑向前隆起，中央保留容纳晶状体的凹窝，外围与后部球面连续连接。悬韧带与睫状体后方保留间隙，皮质不再逐处贴合周边组织的凹凸。外层皮质与更透明的内部凝胶共用玻璃体的选取、剖切及隔离操作；调节改变前部形态，眼轴伸长只作用于后部，两者可独立恢复。

- 拖动模型旋转，滚轮或加减按钮缩放；聚焦画布后可用方向键旋转、`+` / `-` 缩放。四个视角按钮提供斜向、前视、侧视、后视。
- 普通单眼总览以眼球解剖中心为旋转与缩放中心，双眼总览以两眼中心的中点为中心；头骨、光路、注视目标及外围组织只扩大取景范围，不拉偏中心。局部定位、关联观察、晶状体局部和单独查看围绕相应结构，分层/平铺围绕可见布局中心，收拢后恢复眼球中心。已保存的手动平移及局部镜头继续按记录恢复，点击“重置视角”应用当前场景的中心规则。
- 可选结构悬停显示手形与轻度提亮；点击后持续高亮，保留当前镜头和切面。空白处显示抓手，拖动显示抓取状态；拖动不当作点击。
- 列表圆点循环切换显示、半透明、隐藏。半透明及隐藏结构不参与画布选取；从列表选择时恢复目标显示。
- 列表/搜索选择可见目标时保留镜头；目标被遮挡、裁掉或移出画面时切换显露场景并定位。可撤销显露，或只返回定位前镜头。
- 单独查看时改选结构会跟随新目标，退出后恢复之前的图层。小结构按实际几何边界定位，提供材质高亮、名称引线和邻近地标；选中目标不再显示外围虚线圈。
- 搜索支持中英文、拉丁名、结构 ID 和俗称；“黑眼珠”提示虹膜/瞳孔歧义，“眼底”返回分组。疾病词搜索当前返回相关结构，疾病章节从“常见眼病”进入。

十种观察预设按“整体 → 外围组织 → 眼球内部 → 光路”排序：全部结构、眼眶与内容物、结膜与眼睑、眼外肌观察、完整眼球、眼球壁剖面、前段观察、眼内空间、眼底观察、光路观察。每次从明确图层基准重建；眼内空间用边界表达前后房，同时保留玻璃体皮质表面及剖面轮廓，眼底保留黄斑与视盘参照。

每次打开或刷新页面，都进入解剖探索并选中“全部结构”预设：51 个结构图层均为显示，清除单个结构选中与隔离，关闭剖切与分离，开启头骨位置参照并采用斜向整体取景。已有存档、上次所在工作区或关闭头骨的设置不会覆盖这一入口状态；重置场景和清空本地记录后也回到该状态。页面入口只执行一次场景重置，不生成可撤销的旧场景；本次页面内切换工作区后返回探索，保留刚才的图层、镜头及头骨开关。语言、导览进度、题目会话与疾病记录继续保留，进入其他工作区时恢复其草稿。内部结构仍会被外层遮挡，使用剖切、分层/平铺或专门预设细看。

全部结构预设仅用于解剖探索，原有九个预设的组织范围不变，光学、短导览、理解确认和疾病场景保留原来的显示基准。切换预设、撤销、隔离、工作区恢复与中英文继续沿用已有交互；存档格式无需迁移。

自由剖切支持矢状、水平、冠状三轴、位置滑块、拖动平面框及翻转保留侧。切面固定在眼球坐标中，旋转镜头不会改变保留侧；可与分层展开组合。通用观察工作区保留最近 20 条场景撤销，一次连续调节记为一次操作，答案与语言不随撤销倒退。

关联观察包括调节、房水相关结构、眼底地标三组。未选中的关联成员保留次级轮廓与标签，选中成员使用材质高亮与名称引线，支持联合取景、切换成员和返回原场景；房水流出机制的文字说明与局部三维示意见青光眼章节。

### 控件与界面

- 观察预设默认收起，摘要显示当前预设或“自定义视图”；选择后自动收起并恢复焦点，Escape 可关闭菜单。长操作说明按需展开。
- 视角、缩放与撤销集中排列；剖切和分层滑块按宽度并排或换行，轴向、保留侧、阶段和数值持续可见。按钮与滑块保留至少 44px 操作高度及键盘焦点，中英文窄屏均使用紧凑布局。
- 五个工作区使用一致的字号与操作层级；白色资料区和浅灰模型区分开，当前结构、语言和主要操作突出。采用设备字体，无额外字体下载。
- 页面右上角提供 GitHub 仓库角标，在新标签页打开项目源码；包含中英文提示、44px 点击区域和键盘焦点。导航宽度不足时横向滚动，保留语言切换和角标的位置。

### 分层展开与平铺

- 分层滑块仍为 0–100%。前两个三分之一区间沿结构的分离方向增加各层间距；达到最右侧三分之一区间（滑块 67% 起）切换平铺，继续右拉增大格间距。滑块显示阶段、百分比及分界线，并提供中英文与读屏说明。
- 平铺只排列当前显示及半透明的结构，隐藏项保持隐藏；按实际几何尺寸和深度余量分格，保留模型比例、朝向与立体形状。进入平铺切换前视并自动取景，后续仍可旋转、缩放和切换视角；前视用于逐项并列观察。隐藏图层、增加结构或单独查看后重新排列。
- 保留选取、高亮、标签、定位、隔离和场景撤销。从列表显露被隐藏、裁掉或移出镜头的目标时保留平铺，临时关闭剖切以完整显露；可撤销显露。一次连续拖动只记一条撤销，跨越分界后自动前视也纳入场景记录。
- 平铺中按每个结构原来的解剖坐标应用剖切，轴向、位置滑块及保留侧翻转仍可用；不显示跨网格的平面拖动框。回到分层区域后恢复整体固定切面和拖框。分离时剖切范围与框体同步扩展，覆盖展开后的角膜、眼睑和眶部。
- 平铺时暂隐三维光路与神经信号叠加，避免将原位光路画在互相分开的格位之间；参数、二维光学图和演示状态保留，退出平铺后恢复三维叠加。
- 本次页面内切换工作区会恢复平铺值、图层和实际镜头；刷新则按页面入口规则回到全部结构总览，其他工作区仍保留各自草稿。读取旧版记录时，分离值按新的距离倍率换算，不会把旧场景直接切成平铺；新记录保存当前交互版本，无需清空本地数据。

平铺是观察排布，不代表真实空间位置；自由旋转后可能出现透视重叠，可用前视恢复并列观察。大量结构同时显示时小结构仍可通过定位和缩放细看，未另加组织缩放或新交互模式。

### 眼外肌

六肌采用程序生成的扁带状肌腹、纵向纤维和浅色肌腱。四直肌从眶尖方向走向赤道前巩膜；上斜肌在上鼻侧经过滑车折返，止于后颞侧；下斜肌从前鼻下方绕向后颞下方。滑车作为上斜肌的附属参照显示，六肌可分别选取。

- 在解剖探索中点击“眼外肌观察”或“完整眼球”显示六肌；从其他结构预设切入时自动重建显示基准。光路、导览、原有识别题和四章眼病默认隐藏眼外肌，保持原有观察目标。光学工作区不提供眼外肌预设，其“完整眼球”也隐藏六肌，避免正常静态附着与眼轴变化混用。
- 搜索支持眼外肌/EOM 分组，以及中英名称、拉丁名和 SR/IR/MR/LR/SO/IO 精确缩写。资料说明第一眼位的作用与神经支配，鼻颞含义不由屏幕左右决定。
- 复用悬停手形、点击高亮、名称引线、显示/半透明/隐藏、单独查看、分层展开和三轴剖切。肌肉被裁切或遮挡时可定位显露，以半透明巩膜作参照，并撤销回原场景。
- 取景按实际可见结构计算，完整容纳肌肉走行；隐藏肌肉不拉远光路或双眼场景。长肌肉聚焦使用独立取景比例，避免套用小结构缩放后难以辨识。
- 六肌和滑车沿用左右眼镜像与独立资源管理；双眼注视场景默认隐藏静态肌肉。肌肉及标签不随眼轴参数后伸；未建立眶部固定起点、收缩变形、肌力和眼位之间的动态模型。
- 语言切换与本次页面内工作区往返保留选中结构、图层、隔离、剖切及展开值；刷新按页面入口规则回到全部结构总览。读取旧记录时，缺少六肌的图层及隔离前快照补为隐藏，其他工作区草稿、导览与答题记录继续保留，不要求清空存储。

肌肉的尺寸、厚度、间距与肌腱长度用于科普辨识，尚未临床标定；肌肉剖切沿用表面裁切，不额外生成组织学切面或实体封口。眼外肌尚无专门导览和题库主题。

### 结膜与眼睑

在“解剖探索”中选择“结膜与眼睑”，查看上下睑与前部眼球的关系。球结膜覆盖前部巩膜并止于角膜缘，睑结膜衬覆眼睑内面，经穹隆反折与球结膜连续；角膜中央保持开放。

- 上下睑显示皮肤、睫毛参照、眼轮匝肌、睑板和睑结膜。提上睑肌及腱膜只连接上睑。睑板内排列睑板腺，睫毛根附近区分 Zeis 皮脂腺与 Moll 顶泌汗腺。
- 专用预设将皮肤、眼轮匝肌、睑板设为半透明，以便观察内部；保留视网膜、脉络膜后壁，避免瞳孔开口直接透见白色巩膜。可从结构列表切换显示/半透明/隐藏，或选取单项、单独查看、分层展开及三轴剖切。睫毛随皮肤图层显示；上下睑中的同名组织作为一个可选对象。
- 搜索支持中英名称、拉丁名，以及“结膜”“眼睑”、MGD、Zeis/Moll 等别称。MGD 仅定位睑板腺资料，不新增疾病章节或诊断功能。
- 新组织接入悬停、选中高亮、定位、名称标签、剖切、展开、撤销及本次页面内工作区恢复。被遮挡时显露目标，并保留半透明的相邻眼睑/结膜及前眼表面作参照。
- 原有观察预设、基础光路、短导览、理解确认和疾病场景默认隐藏新增组织，继续观察原来的目标；读取旧记录时缺少的新图层补为隐藏，保留其他工作区草稿、隔离前图层和答题记录；页面入口仍展示全部结构。手机仍默认滚页，进入“操作模型”后使用模型手势。

结膜与眼睑是静态结构示意，组织厚度、颜色、腺体数量和间距为辨识作了简化，未经临床标定；未模拟眨眼、腺体分泌、泪膜动力学，也未补齐眶隔、Müller 肌、下睑缩肌或完整泪器。眶脂肪与泪腺见下节。剖切显示表面裁切，不生成眼睑组织学切面封口。

视神经主干采用平滑圆截面管体，保留视盘连接、神经信号演示、选取和剖切。

### 眼眶与内容物

在“解剖探索”中选择“眼眶与内容物”，同时观察骨性眼眶、眼球及周围组织。本组包含 17 个可选对象；眼球、视神经、六条眼外肌和提上睑肌直接复用已有模型，不重复计数。

- 眶上壁、下壁、内侧壁和外侧壁分别选取，形成前方开放、后方收敛并留有开口的骨性轮廓；位置与鼻颞方向沿用成人右眼坐标。骨壁构成写入双语资料，未将七块骨分别建模。
- 眶脂肪分为肌锥内、肌锥外两组，以有限分叶体块表达眼球后方、肌锥和骨壁之间的关系。体块不是独立解剖包膜，也不是实际脂肪体积测量。
- 神经显示动眼神经（III）、滑车神经（IV）、展神经（VI）、V1 的额神经/泪腺神经/鼻睫神经，以及睫状神经节；与已有视神经区分功能。血管显示眼动脉及眼上、眼下静脉的主干与代表性分支；泪腺位于前上颞侧，与眼睑的睑板腺分别说明。
- 同一视神经主干接续到眶尖后口，保留原有控制点、48 段圆截面和末端封口；神经信号路径跟随延长后的几何，取景包含完整后段。
- 专用预设的四面眶壁与两组脂肪为半透明，内部眼球、眼外肌、提上睑肌及主要神经血管显示。可逐层切换、选取高亮、定位、单独查看、三轴剖切、分层展开及撤销；眼眶可见时自动适配取景和剖切框，位置范围扩至眶尖，展开时继续扩展。原有眼球场景保留原来的剖切尺度。
- 搜索“眼眶 / orbit / 眶内容物”返回新增分组；“眶壁”“眶脂肪”、V1、CN II/III/IV/VI、SOV/IOV 可定位对应结构或子集。眼球、眼外肌、视神经和提上睑肌仍在原分组中，完整关系通过专用预设查看。
- 中英切换和本次页面内工作区切换保留场景与选中对象；刷新按页面入口规则回到全部结构总览。读取旧存档及隔离前快照时自动补齐隐藏的新图层。旧预设、导览、题目、光路与疾病场景默认隐藏新增组织；手机滚页/操作模型模式继续复用。新增眶结构及标签不随近视眼轴参数后伸。

当前是静态空间关系示意，不是手术导航或患者影像重建。眶壁厚度、孔口轮廓、神经血管管径及脂肪分叶经过显示性简化；已加入整体头骨外形作位置参照，但未细分七骨及其缝合线、精细视神经管/眶上裂/眶下裂、全部筋膜与血管神经分支。未模拟眶脂肪力学、血流、神经传导病变、泪液分泌或泪道引流，也不新增疾病、导览和测验主题。组织剖切继续采用表面裁切。

## 光路、对照与生理演示

“基础光路”提供正常聚焦、轴性近视、镜片矫正三个基准。二维示意与三维光线读取同一追迹结果，显示瞳孔截光、视网膜等效平面交点、有效样本数、离散程度及聚焦结论。

| 控制项 | 演示内容 |
| --- | --- |
| 眼轴示意增量 | 在屈光基准不变时延长后部眼球，观察焦点与视网膜关系 |
| 物距 | 远处平行入射、较远、较近三档 |
| 调节 | 联动晶状体曲率、睫状体与悬韧带示意 |
| 瞳孔 | 较小、中等、较大三档；开口几何与光束孔径一致 |

选择单变量演示会载入明确基准并锁定其他变量；“自由组合”保留当前参数并解锁。没有有限实焦点、焦点在图外或无有效光线样本时分别说明，不显示无效坐标或虚假的清晰结果。

“保存为对照”冻结参考参数。桌面显示同步旋转/缩放的两模型，窄屏在同一视口切换参考与当前，并保留参数差异摘要。退出对照保留当前参数。本地字形/条纹测试图以交点离散程度表达定性模糊。

## 常见眼病科普

从主导航“常见眼病”进入，首次显示白内障的正常参考。四章共用“正常结构 → 发生什么变化 → 功能会怎样受影响 → 理解确认（可选）”，任何环节均可直接进入，不要求答题后才能继续演示。

当前病种、眼侧、正常/变化状态常驻。正常参考不删除变化参数；再次进入某章恢复该章步骤、参数、镜头与答题。相关结构通过临时资料层查看，关闭后继续本章；“返回原工作区”恢复进入前的模式与草稿。

单眼章节在桌面可同时比较正常与变化，窄屏共用一个视口；斜视和弱视始终显示同一对眼。重置本章只重新演示，保留理解确认记录。

### 白内障

- 定义为晶状体混浊，说明常见年龄相关性白内障的蛋白改变、聚集与散射机制；区分眼球表面覆盖物、单纯失焦与晶状体混浊。
- 成人右眼前段场景，保留角膜、虹膜、睫状体和悬韧带的邻近关系；可切换晶状体局部与眼球内位置。
- 混浊强度为 0—1 的显示参数，只改变晶状体与核区外观，不改变角膜、瞳孔开口、眼轴或晶状体几何。
- 本地对比图展示雾感与对比度下降，点光源场景展示光晕。正常参考保持清晰，变化预览使用当前混浊参数。
- 功能说明包括模糊、对比敏感度下降、眩光、光晕与颜色变淡，并说明表现随混浊位置与程度变化。本章使用均匀混浊、固定屈光参数，未模拟各类型或伴随屈光变化。配套 3 题帮助区分晶状体混浊、角膜病变与单纯失焦。

### 青光眼

- 定义为一组视神经损害疾病，说明视网膜神经节细胞及轴突丢失、神经纤维层和视盘改变，以及眼压作为可干预风险因素的含义；本章侧重开角型相关机制，不模拟闭角机制。
- 房角区域及小梁网提供结构资料与搜索；提供房水流出、眼底与视神经两种观察位。
- 青绿色箭头沿睫状突、后房、瞳孔、前房、房角小梁网排列，可播放或暂停；静态箭头在减少动画时仍保留。文字补全 Schlemm 管、集液管和巩膜表层静脉，并说明葡萄膜巩膜途径；下游通道未建立三维模型。
- 四个独立情景为正常参考、流出受限风险、已有损害、正常眼压损害；它们不是病程阶段，也不计算眼压或损伤百分比。
- 以较少的完整连续路径示意神经纤维丢失，避免以断续线暗示纤维被切断；线条数不是轴突计数或损伤比例，也未模拟视盘凹陷与纤维层厚度。改善流出保留已有损害和缺损；正常眼压情景也可单独显示损害。切到正常参考时，情景按钮同步显示参考状态，变化参数仍保留。
- “未标注缺损的参考图”与自觉症状说明分开，明确早期开角型青光眼可在本人察觉前已有视野损害。视野图用局部斜线区域举例，不表示患者必然看到黑块，也不构成病程或检查结果。配套 4 题区分风险、诊断与损害，解析与新文案一致。

### 斜视与双眼

- 定义为双眼眼位不一致，说明双眼单视、立体视觉及眼球运动控制、屈光和机械限制等相关因素，避免笼统归因为眼外肌无力。
- 左右眼为独立几何与材质实例，左眼地标按鼻颞关系镜像构建并处理三角绕序；点击、高亮、标签及方位标区分 OD/OS。
- 双眼共同指向近/远目标，正常看近时会聚；不能以两条方向线不平行直接判断内斜。
- 内斜、外斜及自定偏差作用于指定眼侧；额外水平偏差范围为 −20° 至 +20°，正值鼻侧、负值颞侧，仅为几何示意，不涵盖垂直等其他类型。
- 可分别讲解眼位、成人可能复视、儿童可能抑制，明确这些体验并非每位患者必然出现。提供进入弱视机制的链接及 3 道配套题。

### 弱视

- 定义为发育期异常视觉经验导致的一眼或双眼最佳矫正视力降低，不能单用眼部结构异常解释；风险因素本身不等于已确诊弱视。
- 用成人双眼几何与“输入 → 视觉处理”图说明儿童视觉发育机制；不把成人模型称为儿童眼球。
- 三类案例为屈光参差、斜视相关、形觉剥夺，每类独立保留原因/异常输入/发育结果卡片位置和输入改善开关。正常参考下隐藏异常机制卡片与改善开关，切回变化示意恢复原设置。
- 屈光参差复用正常与轴性近视基准，文案说明远视、散光差异也可能致病；改善输入通过镜片与共享追迹表达，保持原眼轴。斜视案例改善眼位，形觉剥夺案例解除示意混浊。
- 改善输入后，视觉处理框及第三机制卡同步改为“视觉恢复需随访评估”，说明适当干预可使视力改善，屈光矫正本身可使部分患儿获益；不将清晰输入当作已即时恢复，也不暗示永久不可改善。仅改变输入示意，不计算视力、治疗时间或预后。
- 默认仅演示右眼输入差异；文字补充双眼高度未矫正屈光不正可致双眼弱视，未增加双眼病变模型。4 道配套题同步定义、形觉剥夺和恢复评估的表述。

## 短导览与理解确认
